# Practical 15: Streamlit Based Data App

## Objective
To create and set up a Python environment, install the required libraries, and run a simple interactive web application using Streamlit as per the practical instructions.

## Requirements
The required packages are listed in requirements.txt:
- streamlit
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn

## How to Run

1. Open terminal or command prompt in the project folder.
2. Install dependencies:
   pip install -r requirements.txt
3. Run the Streamlit application:
   streamlit run app.py
4. The application will open in the default web browser at http://localhost:8501.

## Output
The application shows a title, an input field to enter a name, and displays a greeting once submitted.
